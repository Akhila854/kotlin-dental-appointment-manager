# 🦷 Dental Appointment Manager

A Kotlin console-based application for managing dental clinic appointments.

## Features
- Add patients
- Book appointments
- View appointments
- Search patient
- Cancel appointments

## Tech Stack
- Kotlin
- IntelliJ IDEA
- Object-Oriented Programming

## Project Structure
src/
├── Main.kt
├── model/
├── service/

## How to Run
1. Open project in IntelliJ
2. Run Main.kt
3. Use console menu

## Skills Demonstrated
- Kotlin programming
- CRUD operations
- OOP concepts
- Service layer architecture
- Data handling
